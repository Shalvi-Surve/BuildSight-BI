# Data Dictionary

This document defines the fields used by BuildSight BI.

The final dictionary must be updated using the actual downloaded
dataset. The definitions below are provisional examples.

| Field | Description | Expected Type | Unit |
|---|---|---|---|
| Project_Name | Name of the project | Text | Not applicable |
| State | State associated with the project | Text | Not applicable |
| Sector | Project sector | Text | Not applicable |
| Executing_Department | Responsible department | Text | Not applicable |
| Sanctioned_Date | Date of project sanction | Date | Not applicable |
| Approved_Cost | Approved project cost | Decimal | As provided by source |
| Scheduled_Completion_Date | Scheduled completion date | Date | Not applicable |
| Financial_Expenditure | Reported expenditure | Decimal | As provided by source |
| Present_Status | Reported project status | Text | Not applicable |

## Notes
- These are proposed field names, not a claim about the exact source schema.
- Original source column names must be recorded.
- Units and date formats must be verified during Week 2.
- Missing fields should be documented rather than invented.
