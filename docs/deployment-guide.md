## Deployment Goal
Deploy the BuildSight BI companion website using Streamlit Community
Cloud or another compatible hosting platform.

## Prerequisites
- A working Streamlit application
- A GitHub repository accessible to the deployment platform
- A requirements.txt file
- Website-ready processed data
- No embedded passwords, tokens or private credentials

## Deployment Outline
1. Push the tested website code to GitHub.
2. Confirm that requirements.txt includes the website dependencies.
3. Confirm that the application reads the intended data files.
4. Connect the repository to the hosting platform.
5. Select the application entry point.
6. Configure any required secrets using the platform's secret manager.
7. Deploy and test the public URL.
8. Record the deployment URL and date here.

## Data Privacy
Only publish data that is permitted for public redistribution.
Do not publish confidential, personal or restricted information.

## Status
Deployment instructions are preparatory until a live deployment
has been completed and tested.
