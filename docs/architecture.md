# BuildSight BI — System Architecture

## Architecture Overview

The project uses a staged workflow:

1. Public data acquisition
2. Raw data preservation
3. Data inspection and transformation
4. Data validation
5. Data modelling and KPI development
6. Power BI dashboard development
7. Predictive analysis, where suitable
8. Website presentation
9. Final evaluation

## Data Flow

Public Source
    ↓
Raw Dataset
    ↓
Power Query / Python Preparation
    ↓
Validated Processed Dataset
    ↓
Power BI Data Model and DAX
    ↓
Interactive Dashboard

Processed Dataset + Prediction Outputs
    ↓
Shared Website Outputs
    ↓
Streamlit Website

## Components

### Data Sources
Publicly accessible project information with documented source details.

### Data Preparation
Power Query is used to import, inspect, clean and transform the data.
Python may be used for supplementary validation and reproducibility.

### Business Intelligence
Power BI is used for data modelling, measures and dashboarding.

### Predictive Analytics
Python-based modelling may be introduced if the selected dataset has
a suitable target variable and sufficient observations.

### Website
Streamlit presents selected project indicators and outputs generated
by the analytical workflow.

## Data Integrity
The website should consume processed files generated by the project.
Values should not be manually retyped from dashboard screenshots.

## Architecture Status
This is the initial architecture. It will be revised as actual data
fields and implementation decisions are confirmed.
