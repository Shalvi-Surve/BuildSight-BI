# Project Overview

## Project Name
BuildSight BI — Construction Business Intelligence and Analytics Platform

## Overview
BuildSight BI is an educational business intelligence project that
explores how publicly available infrastructure project information can
be organised and analysed to support project monitoring.

The project follows a six-week progression: strategic planning, data
sourcing and preparation, data modelling, dashboard design, predictive
analytics and final evaluation.

## Problem
Project-related information may include cost, expenditure, dates,
status, sector and location. These indicators can be difficult to
compare when they are presented in separate tables or formats.

## Proposed Solution
BuildSight BI will establish a reproducible data workflow using Power
BI, Power Query, DAX and Python. A companion Streamlit website will
present selected results from the processed data.

## Intended Users
- Students learning business intelligence
- Analysts exploring public infrastructure data
- Project-monitoring and planning audiences
- Users interested in understanding project-level indicators

## Scope
The project focuses on fields available in public datasets. It does
not claim access to private contractor records, detailed site reports,
or confidential workforce and procurement information.

## Expected Outcomes
- Documented public data sources
- Cleaned and validated analytical dataset
- Data model and KPI definitions
- Interactive Power BI dashboard
- Predictive analysis, if data suitability is established
- Final evaluation report
- Companion website
