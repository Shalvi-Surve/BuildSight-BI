# Shared Data

This folder contains reusable data files intended to be consumed by
multiple project components.

The Week 2 processed dataset should remain the authoritative cleaned
source. Shared copies should only be created when needed for a specific
application or workflow.

- Source
- Generation date
- Schema
- Transformation script or process
- Intended use
