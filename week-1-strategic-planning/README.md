# Week 1 — Strategic Planning

## Objective
Establish the business problem, intended users, analytical use cases,
initial KPI framework, technology choices and project roadmap for
BuildSight BI.

## Work Covered
- Construction and infrastructure BI context
- Business objectives and stakeholder needs
- Proposed use cases
- Initial KPI framework
- Technology and tool selection
- Conceptual architecture
- Six-week implementation roadmap

## Key Use Cases
1. Project performance monitoring
2. Cost and expenditure analysis
3. Schedule analysis
4. Sector and regional comparisons
5. Project risk exploration

These use cases are provisional and depend on data availability.

## Deliverables
- Formal report: `reports/Week-1/`
- KPI framework: `kpi-framework/`
- Use-case descriptions: `use-cases/`
- Architecture: `architecture/`
- Roadmap: `roadmap/`

## Handoff to Week 2
Week 2 will identify public datasets and test whether their fields can
support the proposed KPIs. The KPI framework may be revised based on
actual data availability.
