# Technology Selection

## Microsoft Power BI
Selected for data import, Power Query transformations, data modelling,
DAX calculations and interactive reporting.

## Power Query
Selected for repeatable data ingestion and transformation.

## DAX
Selected for defining reusable analytical measures within the Power BI
data model.

## Python
Used for supplementary data inspection, validation, predictive
experimentation and website data preparation where appropriate.

## Streamlit
Planned as a companion web application for presenting selected
processed outputs from the repository.

## Git and GitHub
Used for version control, project documentation and source-code
management.

## Decision Principle
Power BI remains the primary BI environment. The website complements
the Power BI deliverable rather than replacing it.
