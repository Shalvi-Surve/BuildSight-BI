# Week 3 — Data Modelling and DAX

## Objective
Develop a structured Power BI data model using the validated dataset
from Week 2 and create reusable DAX measures for supported KPIs.

## Inputs
- Week 2 processed dataset
- Week 2 data dictionary
- Week 2 data-quality report
- Week 1 KPI framework

## Planned Work
1. Identify the dataset's grain.
2. Identify fact and dimension tables where appropriate.
3. Define relationships and cardinality.
4. Create a conceptual model and ER diagram.
5. Implement the model in Power BI.
6. Create at least three relevant DAX measures.
7. Validate measures against independently calculated examples.
8. Document assumptions and limitations.

## Planned Deliverables
- Data model diagram
- Relationship documentation
- DAX measure files
- Power BI model
- Measure validation notes
- Week 3 Word report

## Dependency
The model must use the validated Week 2 data. The design will reflect
the actual fields rather than assuming unavailable fields.
