# Source Selection Rationale

## Primary Candidate: MDoNER Projects Dashboard

The MDoNER project dashboard is selected for initial exploration
because it provides project-level information relevant to infrastructure
project monitoring.

Potentially useful fields include project name, state, sector,
sanctioned date, approved cost, scheduled completion date, financial
expenditure and present status.

The source is regionally focused. Therefore, analysis will be described
as applying to the projects represented in the dataset and not to all
Indian construction projects.

## Supplementary Candidate: PPP in India

The PPP in India project database is considered as a possible
supplementary source. It contains project cost, sector, status,
authority, award date and location fields.

It will not be merged automatically with the primary source. Before
integration, field definitions, reporting dates, project identifiers
and record matching quality must be evaluated.

## Selection Criteria
- Public accessibility
- Downloadable data
- Relevance to project monitoring
- Availability of cost, date and status fields
- Data documentation
- Reproducibility
- Suitability for later Power BI analysis

## Decision
The primary dataset will be finalised after inspecting the downloaded
file and confirming the actual fields and data quality.
