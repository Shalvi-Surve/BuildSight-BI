# Processed Data

This folder contains the cleaned dataset intended for use in Week 3.

A processed file should only be added after:
- Source fields have been inspected.
- Data types have been corrected.
- Missing-value treatment has been documented.
- Duplicate handling has been documented.
- Data-quality checks have been completed.
- The output has been compared with the raw input.

Expected output filename:
`mdoner_projects_cleaned.csv`

The filename is provisional and may be changed to reflect the final
source and transformation workflow.
