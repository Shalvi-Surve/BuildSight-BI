# Raw Data

This folder is reserved for original, unmodified source files.

## Primary Source
MDoNER Projects Dashboard:
https://www.nesetu.mdoner.gov.in/projects/project-list

## Expected File
`mdoner_projects_raw.xlsx`

## Instructions
1. Download the Excel export from the official dashboard.
2. Record the access date and dashboard's displayed data date.
3. Preserve the downloaded file without editing it.
4. Record any filters applied before downloading.
5. Check the source's terms before redistributing the file.

If the original file cannot be redistributed, keep it locally and
provide reproducible download instructions instead of committing it.
