# Week 4 — Interactive Dashboard Design

## Objective
Create an interactive Power BI dashboard based on the validated
Week 3 model and KPI measures.

## Inputs
- Week 2 processed dataset
- Week 3 data model
- Week 3 DAX measures
- Week 1 use cases

## Planned Dashboard Sections
- Project Overview
- Cost and Expenditure
- Schedule and Status
- Sector and Regional Analysis
- Risk Exploration, if supported by data

## Planned Work
1. Design a dashboard storyboard.
2. Select suitable visuals for each KPI.
3. Plan filters, drill-downs and tooltips.
4. Implement the dashboard in Power BI.
5. Test interactions and filtering behaviour.
6. Capture screenshots.
7. Document design choices and limitations.

## Planned Deliverables
- Dashboard storyboard
- Layout and interaction plan
- Power BI dashboard
- Screenshots
- Dashboard testing notes
- Week 4 Word report

## Dependency
Use the validated Week 3 model and measures. Do not redefine KPI
logic independently inside each visual.
