# BuildSight BI — Companion Website

## Purpose
The website is a companion presentation layer for selected outputs
generated by the BuildSight BI analytical workflow.

Microsoft Power BI remains the primary business intelligence tool.
The website does not replace the Power BI model or dashboard.

## Planned Technology
- Python
- Streamlit
- Pandas
- Plotly

## Planned Pages
1. Project Overview
2. Project Performance
3. Cost Analytics
4. Schedule and Status
5. Risk and Forecast
6. Methodology

The final pages will depend on the fields and analytical outputs
available in the completed project.

## Data Inputs
The website should use processed data and generated outputs from
the repository's shared data folders.

It should not depend on manually copied chart values.

## Run Locally

From the repository root:

```bash
pip install -r requirements.txt
streamlit run website/app.py
